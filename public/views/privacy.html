Privacy

BudaBit Calls is a pilot service. Rooms and chat state are held in memory and are discarded when the service restarts. Server-side recording, RTMP streaming, analytics, geolocation, AI integrations, payments, and advertising are disabled.

Audio, video, and screen-sharing media are encrypted in transit and forwarded by the BudaBit-operated mediasoup server. Media is not end-to-end encrypted against the server. Other participants can see and hear media you choose to share.

Operational logs may retain IP addresses, request paths, errors, and resource usage for security and reliability. Access logs omit URL query strings because direct-join links can contain room passwords. Debug logging is disabled.

The room interface loads required user-interface libraries from third-party CDNs. Those providers receive normal web request metadata such as your IP address and browser headers. Do not use the pilot for highly sensitive conversations.
